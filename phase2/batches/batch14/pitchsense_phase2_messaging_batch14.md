# PitchSense AI — Phase 2: Competitor Website Messaging and Landing Page Analysis (Batch 14)

**Research date:** October 20, 2026 (Europe/Berlin). Added in the Oct 20 scope swap (replacing six weak-fit companies). Homepages were captured as HTML in the light format, then analysed in the full format the same day, with one CRO-relevant supporting page per company.

**Scope:** Revenue Grid (https://revenuegrid.com/; CRO page: https://revenuegrid.com/product/sales-forecasting/); Weflow (https://www.weflow.ai/; CRO page: https://www.weflow.ai/solutions/executives). Phase 1 discovery, classification and capability scoring are not repeated here.

**Method and verification scope.** Heading levels were verified against HTML tags in the saved pages, in document order; nav, mega-menu, footer, tab and responsive duplicates were excluded. Every exact-copy field (Table A hero fields, Table B headings and subheadings, Table D CTA labels, Table E claims and the quoted text in Table F) was string-matched against the saved captures after normalising whitespace, HTML entities and curly quotes; values split across inline tags were matched word by word and are noted in their rows. CTA destinations are the `href` in the HTML; destinations that were not fetched are marked "intent unverified". All captures are in `captures/` in this folder.

**Limitations.** (1) HTML only: no rendered-browser check was possible for this batch, so visual hero media, client-side rotating headlines and script-rendered content are labelled as such rather than confirmed. (2) Table A hero fields equal the light-format row (`website_messaging_batch14.csv`); Not-verified light fields were re-checked the same day and any field filled is noted in that row's Verification cell as "Gap-fill". (3) Table F was written directly against PitchSense Product Narrative v1 (Sep 30, 2026); its PitchSense column is copied verbatim from batches 1–3. (4) Vendor metrics, testimonials and badges are vendor claims, recorded verbatim and not verified. Messaging emphasis is not evidence that a capability is missing.

**Canonical data:** the `table_*.csv` files in this folder. This report renders them; if a table changes, re-render the table sections.
