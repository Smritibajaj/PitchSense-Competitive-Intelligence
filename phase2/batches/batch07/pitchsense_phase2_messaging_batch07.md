# PitchSense AI — Phase 2: Competitor Website Messaging and Landing Page Analysis (Batch 7)

**Research date:** October 19, 2026 (Europe/Berlin). Homepages were captured as HTML for the light-format pass; the batch was upgraded to the full format the same day, adding one CRO-relevant supporting page per company.

**Scope:** Siro (https://www.siro.ai/; CRO page: https://www.siro.ai/evaluate); Microsoft (Copilot for Sales) (https://adoption.microsoft.com/en-us/copilot-for-sales/; no separate CRO page used); Salesforce (Agentforce) (https://www.salesforce.com/agentforce/; CRO page: https://www.salesforce.com/sales/); Fathom (https://www.fathom.ai/; CRO page: https://www.fathom.ai/solutions/sales); Otter.ai (https://otter.ai/; CRO page: https://otter.ai/sales-agent). Phase 1 discovery, classification and capability scoring are not repeated here.

**Method and verification scope.** Heading levels were verified against HTML tags in the saved pages, in document order; nav, mega-menu, footer, tab and responsive duplicates were excluded. Every exact-copy field (Table A hero fields, Table B headings and subheadings, Table D CTA labels, Table E claims and the quoted text in Table F) was string-matched against the saved captures after normalising whitespace, HTML entities and curly quotes; values split across inline tags were matched word by word and are noted in their rows. CTA destinations are the `href` in the HTML; destinations that were not fetched are marked "intent unverified". All captures are in `captures/` in this folder.

**Limitations.** (1) HTML only: no rendered-browser check was possible for this batch, so visual hero media, client-side rotating headlines and script-rendered content are labelled as such rather than confirmed. (2) Table A hero fields equal the light-format row (`website_messaging_batch7.csv`); Not-verified light fields were re-checked on Oct 19, 2026 and any field filled is noted in that row's Verification cell as "Gap-fill". (3) Table F was written directly against PitchSense Product Narrative v1 (Sep 30, 2026); its PitchSense column is copied verbatim from batches 1–3. (4) Vendor metrics, testimonials and badges are vendor claims, recorded verbatim and not verified. Messaging emphasis is not evidence that a capability is missing.

**Canonical data:** the `table_*.csv` files in this folder. This report renders them; if a table changes, re-render the table sections.

## Final Strategic Analysis

All statements below are analyst interpretation grounded in the tables above. Vendor claims are the vendors' own statements, preserved verbatim; they are not independently verified. CTA frequency is recorded, not treated as evidence of conversion effectiveness. No PitchSense landing-page copy is written here.

### 1. Dominant homepage narrative of each competitor

- **Siro** runs a niche-ownership narrative: "AI for in-person sellers." ([homepage](https://www.siro.ai/)). The page sets field selling against inside-sales tools ("Most AI sales coaching tools were built for video calls and inside sales teams.") and calls itself "an end-to-end sales performance system".

- **Fathom** leads with presence in the meeting ("so you can focus on the conversation") and then quantifies time saved ("6+ hours saved") before the team-function cards ([homepage](https://www.fathom.ai/)).
- **Otter** leads with a feature list in the hero ("Transcription. Pre-call briefs. Live coaching. Automatic follow-ups.") and states value as "turns talk into action"; it is the most feature-first of the five ([homepage](https://otter.ai/)).

None of the five uses the phrase *shared memory* or *organizational memory* on the inspected pages.
