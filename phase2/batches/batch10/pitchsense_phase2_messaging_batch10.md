# PitchSense AI — Phase 2: Competitor Website Messaging and Landing Page Analysis (Batch 10)

**Research date:** October 19, 2026 (Europe/Berlin). Homepages were captured as HTML for the light-format pass; the batch was upgraded to the full format the same day, adding one CRO-relevant supporting page per company.

**Scope:** Uniphore (https://www.uniphore.com/; CRO page: https://www.uniphore.com/use-cases/front-office/revenue-operations/); Level AI (https://thelevel.ai/; CRO page: https://thelevel.ai/solutions/sales-performance); Balto (https://www.balto.ai/; CRO page: https://www.balto.ai/contact-center-insights/); Mediafly (https://www.mediafly.com/; CRO page: https://www.mediafly.com/solutions/revenueleaders/); SalesHood (https://saleshood.com/; CRO page: https://saleshood.com/sales-enablement-platform/impact-insights/). Phase 1 discovery, classification and capability scoring are not repeated here.

**Method and verification scope.** Heading levels were verified against HTML tags in the saved pages, in document order; nav, mega-menu, footer, tab and responsive duplicates were excluded. Every exact-copy field (Table A hero fields, Table B headings and subheadings, Table D CTA labels, Table E claims and the quoted text in Table F) was string-matched against the saved captures after normalising whitespace, HTML entities and curly quotes; values split across inline tags were matched word by word and are noted in their rows. CTA destinations are the `href` in the HTML; destinations that were not fetched are marked "intent unverified". All captures are in `captures/` in this folder.

**Limitations.** (1) HTML only: no rendered-browser check was possible for this batch, so visual hero media, client-side rotating headlines and script-rendered content are labelled as such rather than confirmed. (2) Table A hero fields equal the light-format row (`website_messaging_batch10.csv`); Not-verified light fields were re-checked on Oct 19, 2026 and any field filled is noted in that row's Verification cell as "Gap-fill". (3) Table F was written directly against PitchSense Product Narrative v1 (Sep 30, 2026); its PitchSense column is copied verbatim from batches 1–3. (4) Vendor metrics, testimonials and badges are vendor claims, recorded verbatim and not verified. Messaging emphasis is not evidence that a capability is missing.

**Canonical data:** the `table_*.csv` files in this folder. This report renders them; if a table changes, re-render the table sections.
