# PitchSense Competitive Intelligence

Competitive-intelligence research for PitchSense AI (Revenue Intelligence / Sales Enablement / Conversation Intelligence / AI Sales Technology), maintained in this Project.

## Research state (as of October 19, 2026)

- 50 companies researched and scored across four batches (Oct 17-19, 2026).
- Consolidated master report is the current source of truth: `reports/pitchsense_competitor_research_master.md`.
- Batch reports 1-3 are per-batch detail records; batch 4 is documented inside the master report (no separate batch file).
- All scores follow the frozen rubric (five dimensions, 0-2 each, max 10): Call Intelligence, Deal Intelligence, Content Intelligence, Coaching Intelligence, Shared Memory.
- Verified facts are separated from assumptions; unverified capabilities are marked and excluded from confirmed totals.

## File index

- `reports/pitchsense_competitor_research_master.md` — consolidated 50-company master report: batch-4 notes, Tables A/B/C (all 50 companies), final synthesis (top-10, shared-memory five, CRO five, themes, three gap hypotheses), verification gates.
- `reports/pitchsense_competitor_research_batch1.md` — batch 1 (14 companies: Gong, Outreach, Salesloft+Clari, Sybill, Aida, Mindtickle, Second Nature, Allego, Seismic+Highspot, Avoma, Backstory, WINN.AI, Attention, Momentum).
- `reports/pitchsense_competitor_research_batch2.md` — batch 2 (9 companies: ZoomInfo Chorus, Jiminny, Fireflies.ai, Observe.AI, Noota, Traq.ai, Balto, Circleback, tl;dv).

## Key results

- Top 10 (by capability overlap with PitchSense's vision): Gong 8; Aida, Attention, Outreach, Showpad, Allego, Mindtickle 7; Sybill, Traq.ai, Avoma 6.
- Shared-memory five: Sybill, Aida, Gong, Backstory, Attention (Aviso strongest challenger).
- CRO five: Salesloft+Clari, Gong, Backstory, Attention, Aviso.
- Three gap hypotheses (testable, not verified absences): conversation memory connected to approved content; a sales-org memory layer spanning calls/emails/CRM/content; deal-grounded content generation with governance.
- No PitchSense positioning recommendation has been made (per the research brief, positioning decisions follow the evidence).
